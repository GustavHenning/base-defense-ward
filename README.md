# base-defense-ward

Valheim mods plus an isolated, scriptable test harness.

- `mods/base-defense-ward/` – the Base Defense Ward mod (published to Thunderstore/Nexus).
- `tools/` – dev profile setup, launcher, debug socket client, end-to-end test, packaging.
- `AGENTS.md` – the short version of how to work in this repo, for humans and coding agents.

Quick start:

```
tools\setup-profile.ps1
tools\test-e2e.ps1
```
