# Base Defense Ward

Adds a **Base Defense Ward** build piece to the Hammer (Misc tab). It uses the vanilla ward's
model and private-area behaviour, and glows blue while it is active.

- Requires BepInEx 5.4.23 or newer (Valheim runs on Unity 6).
- Client-side piece registration; all players who see the piece need the mod installed.
- Currently costs nothing to build (placeholder recipe while the mod is in development).

## Install

Drop `BaseDefenseWard.dll` into `BepInEx/plugins/`, or install through r2modman / Thunderstore.
